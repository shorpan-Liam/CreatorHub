# 文章转图片：产品功能规格

版本：0.1 · 工具 slug：`article-to-images` · 优先级：P0

## 1. 目标与成品

输入一篇结构不固定的中文文章，输出多张可直接上传的图片。图片具备内嵌个人标识、首图大标题、清晰正文、合理分行及分页。用户可微调，但不需要逐张复制内容。

默认模板为白底、深色文字、宋体风格正文、首图标题浅灰强调线。个人品牌默认文字“小潘同学”，不强制提供头像。封面采用“标题 + 开篇正文”，后续页面继续正文。完整标题默认仅出现于首页，每页顶部重复品牌标识。

## 2. 编辑器布局与主流程

- 桌面 ≥1280px：左侧内容、中间预览、右侧样式，底部或顶部固定主要操作。
- 768–1279px：内容和预览双栏，设置放抽屉。
- <768px：内容 / 预览 / 样式三个页签；下载入口常驻；保持编辑状态。
- 中央预览下方展示页缩略图、页码与总页数，可单击切换；不提供图片重排，顺序跟随正文。

主流程：输入文章 → 检查标题 → 选择品牌和比例 → 查看即时草图 → 生成高清预览 → 微调并重新生成 → 下载全部或单页。

“即时草图”使用当前浏览器排版；“高清预览”由服务端固定 Chromium 生成，是下载结果的依据。若两者在字体或换行上不同，应提示以高清预览为准。编辑后旧结果标记“内容已更新，请重新生成”。

### 3.1 格式转换规则

- 首个一级 Markdown 标题仅在独立标题字段为空时提议转为标题；用户确认后迁移，不把任意第一行当标题。
- 纯文本保留单换行作为软换行；空行形成新段落。跨应用粘贴形成大量断行时，提供主动“合并段内换行”操作及撤销。
- Markdown 链接显示链接文字与 URL，保证信息未静默丢失；图片、表格、代码块、深层嵌套列表作为原样文本并提示不支持专门排版。
- 不执行输入中的 HTML、脚本或其他指令，原始 HTML 按文本展示。
- 支持中文、英文、数字、标点和常见 Emoji；缺字警告与替代字体由渲染结果决定，不把空白方框当成功。
- 保留来源文本与显示内容的映射，用于检查结构转换后的内容一致性；Markdown 标记本身不是必须出现在图片上的正文。

## 5. 自动分行与分页规则

| ID | 规则 | 优先级与降级 |
| --- | --- | --- |
| IMG-023 | 实际测量 | 按真实字体、字号、字重、行距和容器宽高测量，禁止按每页固定字数切分 |
| IMG-024 | 标题分行 | 优先标点和短语边界，避免一行只剩一个字；超长标题占满首页时允许标题独立成页 |
| IMG-025 | 段落完整 | 短段可完整放入下一页时优先整体移动；不得因此创建没有内容的页面 |
| IMG-026 | 长段拆分 | 优先句末，再考虑逗号/分号所在行边界，最后在安全的字素簇边界切分 |
| IMG-027 | 孤行控制 | 段落跨页时尽量使两页各至少两行；极限条件无法满足时提示，不能丢字或溢出 |
| IMG-028 | 标题跟随 | 小标题与至少两行后续正文一起排；不足两行的正文整体跟随 |
| IMG-029 | 中文标点 | 避免逗号、句号、右括号落在行首，左括号落在行尾；不能破坏 Emoji 组合字符 |
| IMG-030 | 显式分页 | 用户分页优先；首尾分页、连续分页折叠且提示，不产生空白导出页 |
| IMG-031 | 容量上限 | 最多 50 页是工具初始限制，不是小红书限制；超限阻止导出，建议拆为多篇 |
| IMG-032 | 防溢出 | 每页检查边界；无法放下的不可拆块返回定位信息，让用户修改，禁止静默裁切 |

约束冲突优先序：内容完整 > 不溢出 > 用户分页 > 小标题跟随 > 孤行控制 > 段落完整 > 页底均衡。

不按相同像素高度切割一张长图；逐页排版与绘制。最后一页可留白，不通过拉大行距强行撑满。第一版不承诺中文分词绝对正确，允许人工调整。

## 7. 草稿与备份

- IMG-042（P0）：变化后约 1 秒防抖保存到 IndexedDB；保存失败显示持续提示，不能显示“已保存”。
- IMG-043（P0）：支持命名、新建、恢复、复制、删除本机草稿，最多 20 份；达到上限要求用户管理，不自动删除旧稿。
- IMG-044（P0）：导出 `.creatorhub.json`，包含 schemaVersion、文章块、品牌设置、Logo 数据、模板版本、样式和显式分页，不包含匿名会话令牌或临时下载 URL。
- IMG-045（P0）：导入验证版本、字段、尺寸及大小（备份文件 ≤10 MiB），新建草稿，不覆盖已有作品；不支持版本提供解释。
- IMG-046（P0）：同一草稿多标签页编辑时检测 revision 冲突，提供重新载入或保存副本，不静默最后写入覆盖。

## 8. 非功能与边界

首版目标浏览器为桌面 Chrome/Edge，手机 Chrome/Safari 需验证输入、恢复、预览和单页下载。API 离线时已有草稿仍可编辑，新增高清渲染不可用；首次离线打开站点不保证可加载。

不限制用户文章主题，不代替用户判断文章事实；排版工具不执行文章中夹带的指令。真正的平台发布效果，需要用自有或允许测试的内容实际验证信息流封面、笔记阅读、放大查看三种状态，并记录 App 版本。

AI、自动发布、正文插图、复杂表格、可视化自由画布均在首版范围之外。

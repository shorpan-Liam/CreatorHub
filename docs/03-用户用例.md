# CreatorHub 用户用例与验收场景

版本：0.1 · 日期：2026-09-23

本文件按用户目标组织用例。每个场景包含可验证结果；功能编号对应平台及工具 PRD。下文的“用户”默认均为未登录访问者。

## UC-01 找到并进入工具

- 关联：HUB-001～008、014。
- 前置：至少有一个 `available` 工具。
- 主流程：打开首页 → 搜索“文章” → 筛选“小红书” → 点击“文章转图片”。
- 结果：进入工具编辑器，无账号要求，最近使用增加一条。
- 分支：搜索“字幕”且没有可用结果，显示无结果及清除按钮；规划工具不可当作可用工具启动。
- 验收：同一工具反复进入仅保留一条最近记录；筛选逻辑与 PRD 一致；刷新不丢失收藏。

## UC-02 把有段落的文章转换为图片

- 关联：IMG-001～004、014～020、023～039。
- 前置：Python API 和渲染 worker 可用。
- 主流程：输入标题 → 粘贴 1,500 字、有多个段落的原创文章 → 使用默认样式 → 生成高清预览 → 下载 ZIP。
- 结果：得到同尺寸、有顺序、含“小潘同学”品牌的多张 PNG。
- 验收：所有正文在分页映射中出现且只出现一次；首图有大标题；内页没有重复完整标题；ZIP 页数等于预览页数；单图与 ZIP 同页文件哈希一致。

## UC-03 输入没有任何分段的长文

- 关联：IMG-004、005、023～032。
- 前置：原文模式。
- 主流程：粘贴无空行的 3,000 字文章 → 生成 → 查看分页 → 手动拆一段 → 再生成。
- 结果：长段能够安全跨页，人工拆分改善阅读节奏；内容措辞不变。
- 验收：不能要求开启 AI 才能生成；不按字符数量生硬截页；单段超过整页时仍正常终止并分页，无死循环。

## UC-04 导入包含 Markdown 的文章

- 关联：IMG-001～005。
- 主流程：粘贴一级标题、二级标题、加粗、列表、引用和链接 → 查看结构识别 → 确认一级标题迁移。
- 分支：用户已有独立标题，则正文一级标题不自动覆盖；表格/代码块显示为原样文本并提示。
- 验收：脚本片段不执行；链接地址不被静默删除；列表编号可连续；存在原文快照可回看。

## UC-05 设置个人品牌

- 关联：HUB-009、IMG-011～013。
- 主流程：名称改为“小潘同学” → 上传 Logo → 选择圆形显示 → 存为默认品牌 → 新建作品。
- 结果：新作品继承品牌，当前作品每页品牌一致，旧作品保持自己的配置。
- 分支：上传 SVG、超 5 MiB 或损坏图片被拒绝，现有 Logo 保留。
- 验收：服务器实际解码校验，不仅看文件扩展名；无 Logo 时名称仍可独立显示；清空名称并关闭 Logo 后无空白品牌占位。

## UC-06 调整标题分行

- 关联：IMG-006、016、024。
- 主流程：输入约 30 字标题 → 查看自动换行 → 在短语后加入换行 → 再次预览。
- 结果：显式换行优先，标题宽度不越界。
- 分支：100 字以内但标题高度超过首页容量，提示修改字号或标题；只有在足以完整放入一页时才允许标题独占首页。
- 验收：不悄悄把标题压到最小字号以下；长英文词、Emoji、括号组合不出现半个字符或裁切。

## UC-07 控制段落分页

- 关联：IMG-007、025～030。
- 主流程：选择某段“从下一页开始” → 增大正文到 44px → 重新预览 → 移除手动分页。
- 结果：调整样式时分页标记保留；移除后恢复自动分页。
- 分支：连续分页、文章开头/结尾分页不产生空白页。
- 验收：下一页不会只有标题没有正文；若孤行与用户分页冲突，保留分页并给出可理解提示。

## UC-08 切换图片比例

- 关联：IMG-015、023、034、040。
- 主流程：从 1080×1440 切换到 1080×1920 → 查看草图 → 重新生成高清图片。
- 结果：所有页面重新排版、同一批次尺寸一致，文字内容和手动分页不变。
- 验收：旧高清预览标记过期；不能让下载按钮把旧尺寸文件当作新尺寸结果；高版标识为需实际平台验证的预设。

## UC-09 中断后恢复草稿

- 关联：HUB-010、IMG-042、043、046。
- 主流程：编辑文章、品牌和分页 → 等待“已保存” → 关闭浏览器 → 再次打开恢复。
- 结果：恢复内容、样式、品牌及分页；已有导出任务可在匿名会话有效时重新查询。
- 分支：浏览器存储配额不足时显示未保存，提供导出项目备份；多标签编辑时提供保存副本。
- 验收：不能把草稿恢复等同于云同步；新建操作不覆盖原草稿。

## UC-10 转移作品到另一设备

- 关联：IMG-044、045。
- 主流程：导出 `.creatorhub.json` → 另一浏览器导入 → 生成高清图片。
- 结果：内容、Logo、样式和分页一致；重新上传过期素材；无需原浏览器的匿名会话。
- 分支：未知未来 schemaVersion 或超 10 MiB 文件被拒绝，已有草稿不变。
- 验收：备份文件不包含 Cookie、服务端密钥、任务访问凭证或本地磁盘路径。

## UC-11 手机上保存图片

- 关联：HUB-012、IMG-038、041。
- 主流程：390px 宽界面粘贴 → 切换预览页签 → 生成 → 单页下载或打开图片使用系统保存。
- 结果：核心操作不需要桌面设备，输入框不被固定操作条遮挡。
- 验收：分别记录 Android Chrome、iOS Safari 的下载表现；无法自动写相册时展示操作说明，不假报保存成功。

## UC-12 导出期间继续编辑

- 关联：IMG-034、035、040。
- 主流程：版本 A 开始生成 → 修改正文形成版本 B → A 完成 → 生成 B。
- 结果：A 的图片标记属于旧版本；B 的文字不会被 A 覆盖。
- 验收：每批成品关联内容 revision 与配置哈希；下载当前版本必须匹配；重试同一网络请求不会创建重复任务。

## UC-13 生成失败、取消与恢复

- 关联：IMG-035、039。
- 主流程：发起生成 → worker 中断 → 重启 worker → 查询任务。
- 结果：任务经租约回收后重新尝试，达到上限后明确失败；正文仍可编辑。
- 分支：用户取消，任务最终为 cancelled；部分中间文件不作为完整 ZIP 发布；字体加载失败提示重新生成。
- 验收：没有永远停留 running 的任务；用户取消不被自动重试重新激活；失败信息包含请求编号，不泄露服务器路径。

## UC-14 导出过期或服务离线

- 关联：IMG-039、042。
- 主流程：任务完成超过 24 小时 → 点击下载。
- 结果：提示结果已过期，可从草稿重新生成；无效链接不让用户误认为稿件丢失。
- 分支：API 离线时继续编辑已有页面中的草稿，恢复服务后再生成。
- 验收：本机草稿与临时结果分别处理；清理结果不删除本机文章。

## UC-15 数据隔离与清理

- 关联：HUB-013，以及技术设计的匿名会话约束。
- 主流程：浏览器 A 上传 Logo、生成任务 → 浏览器 B 尝试读取 A 的任务和图片。
- 结果：B 得不到 A 的资源；仅知道 UUID 也不可访问。
- 分支：A 清理“服务器临时数据”，进行中的任务取消，素材和结果进入安全删除流程；A 清理“本机数据”只影响明确列出的本机项。
- 验收：对 A 的任务、资产、下载分别检查归属；未知及非本人资源统一返回 404，减少资源枚举。

## UC-16 超长内容与极端版式

- 关联：IMG-009、016～018、031、032。
- 输入集合：空文章、仅标题、20,001 码点正文、超长 URL、50 页边界、最大字体配最小留白。
- 结果：空文章禁止生成；仅标题可导出单页；超长内容和超页数说明原因；不依赖自动删字解决溢出。
- 验收：产品限制在前后端一致，绕过前端仍由后端拒绝；错误定位到字段或内容块。

## UC-17 可选 AI 整理（P1）

- 前置：运营者已配置模型服务，用户明确点击 AI 整理。
- 主流程：提交文本 → 获得结构化建议 → 查看差异 → 部分或全部应用。
- 分支：未配置模型、超时或响应非法时保留原文，可继续普通排版。
- 验收：不自动发布、不默认传送整篇文章到第三方；明确说明发送范围；不让模型输出任意 HTML/CSS/脚本执行。

## 用例执行记录模板

每次发布记录：用例编号、构建版本、浏览器及系统、输入样例 ID、结果、截图或输出文件、缺陷编号。不能用“页面打开成功”代替渲染和完整性验收。

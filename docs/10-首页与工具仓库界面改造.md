# 首页与工具仓库界面改造

日期：2026-10-02。项目：CreatorHub。

更新：本次已将首页从手写CSS近似实现改为TweakCN组件与Tailwind源码移植。详细结构与尺寸见[前端源码移植](11-TweakCN前端源码移植.md)，旧版Hero视口拉伸及连续clamp间距已撤回。

## 目标与来源

按照用户选择，首页参考 [TweakCN](https://github.com/jnsahaj/tweakcn)，工具仓库参考 [BentoPDF](https://github.com/alam00000/bentopdf)，卡片改为横向长方形瀑布流。继续使用本地 Python、React、PostgreSQL，无 Docker、无登录。

核对 TweakCN 的 `app/page.tsx`、`components/home/header.tsx`、`hero.tsx`、`features.tsx`、`how-it-works.tsx`、`faq.tsx`、`cta.tsx`、`theme-preset-buttons.tsx` 及 `components/footer.tsx`，适配居中导航、主次操作、字体对比、功能介绍、三步流程、FAQ 与底部入口。采用项目已有 React Router、Radix 和 CSS，无需引入 Next.js。Apache-2.0 授权文本保存在 `licenses/TweakCN-Apache-2.0.txt`。

根据本次补充要求，首页独立承担平台介绍职责。去掉内嵌工具仓库及其 API 查询，使用真实作品样例介绍输出效果。TweakCN 的主题预设展示改为当前创作能力介绍，省去不符合本项目业务的 AI 付费、社区、GitHub 星数和用户证言，不使用未经证实的用户或工具数量。保留其区块组织、主次按钮、勾选功能列表、图标容器、双列能力区、数字步骤、折叠 FAQ 及多列页脚。

核对 BentoPDF 的 `simple-index.html`、`src/js/ui.ts`、`src/css/landing.css`，参考搜索、工具目录和工作区分离的交互结构。未复制其 AGPL 实现、品牌或商业素材。横向卡片和瀑布流由 CreatorHub 自行实现。

## 页面与布局

| 路由 | 内容 |
| --- | --- |
| `/` | 独立平台介绍：CreatorHub 品牌、定位、真实作品样例、六项已实现能力、创作流程、FAQ 和进入仓库入口 |
| `/tools` | 独立创作工具仓库，搜索、全部/收藏/最近使用筛选、工具入口和继续草稿 |
| `/tools/article-to-images` | 原文章转图片工作区，返回链接指向 `/tools` |
| `/help`、`/settings` | 保留原帮助、本机设置 |
| `/_render`、`/api/v1` | 保留原渲染入口和后端 API |

仓库使用 CSS columns，宽度至少 1200px 时三列，768–1199px 两列，更窄时单列。列间距和卡片间距为 20px，手机为 16px。卡片保持横向结构，左侧完整缩略图，右侧名称、简短说明与平台；标题和说明最多两行。收藏按钮独立于工具链接，继续草稿放在底部。

卡片高度随实际文字、状态和草稿入口变化，`break-inside: avoid` 避免卡片跨列拆开。CSS 多列按列阅读和排列，键盘顺序跟随 DOM。当前实际仅上线文章转图片工具，因此生产页面不填充虚构条目；多卡片、长标题与高度变化通过测试专用目录验证。

首页不展示具体工具目录、搜索或收藏控件，也不请求 `/api/v1/tools`。直接采用TweakCN的Tailwind容器、上下间距、48/60/72/96px标题断点、672px说明宽度、48px按钮、40px操作间距、48px特点列表间距和80px展示条间距。只在外壳保留`min-h-[100dvh]`，区块随内容自然撑开。中文标题使用均衡换行避免单字独占一行，不改变原字号和尺寸断点。

首页导航包含平台功能、创作流程、常见问题和工具仓库，所有主要创作入口都指向 `/tools`。手机菜单支持键盘与 Escape。导航使用 React Router 客户端切换：旧页面卸载后挂载当前路由，只有一个页面容器；200ms淡入，不叠加旧页面退场。`useLayoutEffect` 在绘制前复位滚动，禁用浏览器自动恢复历史位置以避免竞争。页内锚点保留自然滚动行为。滚动条空间仅应用于网站外壳，不影响 `/_render` 出图尺寸。

Motion 实现首屏依次淡入上移、展示条缩放入场和滚动区块首次出现；页头滚动后增加半透明背景。能力展示沿用三行、200px条目、16px间距与四份复制，支持悬停/手动/离开视口暂停。系统减少动态效果偏好通过 `useSyncExternalStore` 监听，支持运行时切换。FAQ 使用 Radix Accordion 的高度动画和键盘导航。手机样例采用横向吸附滚动，图片查看器支持方向键、Escape 和关闭后焦点恢复。首页及 Motion 依赖独立延迟加载，不加入工具页面首次加载的业务包。

## 实现与兼容

- `frontend/src/pages/Landing.tsx`、`landing.css`：独立首页、响应式 Hero、作品展示、Features、HowItWorks、FAQ、CTA 与专用 Footer。
- `frontend/src/pages/components/LandingMotion.tsx`、`CapabilityMarquee.tsx`、`LandingShowcase.tsx`：动效、能力循环展示、真实样例及图片查看器。
- `frontend/src/components/layout.tsx`：页头、手机菜单、页脚。
- `frontend/src/features/catalog/Repository.tsx`、`ToolCard.tsx`、`catalog.css`：共享目录、横向卡片与瀑布流。
- `frontend/src/app/App.tsx`：首页和独立仓库路由、路由滚动复位。
- `scripts/generate_landing_previews.py`：通过真实渲染 API 生成首页静态 WebP；使用独立匿名会话并在完成后清理。

未变更数据库结构、接口协议、草稿格式或浏览器存储标识。原纯文本/Markdown、署名与 Logo、分页、两汉字首行缩进、手动边距和边距收藏、PNG/JPG、单页和 ZIP、撤销重做、备份与异常提示继续可用。改造前源码已备份到 `storage/ui-before-tweak-bento-*.zip`，不包含数据库和浏览器本机数据。

## 验证

前端类型检查、生产构建、10项单元测试及格式检查通过。28项桌面/手机端到端测试覆盖独立首页、源代码尺寸机制、页内锚点、FAQ键盘导航、展示条、样例查看器、搜索收藏、横向瀑布流、草稿恢复、边距收藏、首行缩进、真实出图与ZIP、异常重试、备份菜单和弹窗。

新增导航回归从首页底部连续三次进入仓库并执行前进/后退：检查整个过程没有文档请求，`performance.timeOrigin` 不变，只有一个 `main`，没有残留首页或首页页脚，仓库标题和搜索框在视口内且滚动位置为0。

响应式检查包含320×568、390×844、844×390、768×1024、900×620、1280×720、1536×864、1920×1080、2560×1440、Tailwind各断点边界，以及说明文字放大。验证无溢出、导航不重叠、自然内容高度、容器一致和卡片横向比例。验证截图存放于`storage/`和`frontend/test-results/`；多工具截图仅为测试数据。

本次不改变后端业务。构建中的 Zod 注释提示不影响构建结果；外部平台真实上传后的裁切仍需实际 App 验证。

# 开发计划、风险与验收

版本：0.1 · 日期：2026-09-23

执行更新：已完成首个本机可运行版本和主要出图流程验证。以下保留原始开发任务基线，不把未经验证的细则勾选为完成；实际结果与剩余项详见 `08-首版实现与验证记录.md`。

## 1. 开发顺序

先验证中文分页和图片导出，再搭建完整工具交互。首版不依赖 AI、账号体系、Docker 或外部内容平台接口。

| 阶段 | 任务 | 产物 | 退出条件 |
| --- | --- | --- | --- |
| M0 环境与渲染验证 | 项目隔离环境、React 单页模板、Python Playwright、字体、分页小样 | 可复现的 1/5/20 页样例和环境记录 | 固定尺寸导出；字体正确；跨页不缺字；Windows 子进程可运行 |
| M1 平台骨架 | Vite 路由、FastAPI、PG 迁移/种子、工具目录、匿名会话 | 可进入工具的首页及真实目录接口 | 搜索/筛选/收藏/最近使用可用，刷新路由正常 |
| M2 编辑与布局 | 结构化正文、标题分行、品牌、样式、分页、草稿 | 可编辑和恢复的工作区 | 覆盖 UC-03～09，极端输入不溢出 |
| M3 渲染闭环 | 资产上传、任务表/worker、轮询、高清预览、PNG/JPG/ZIP | 可下载成品 | UC-02/10/12～16，输出完整、版本一致、可重试 |
| M4 体验与验收 | 手机下载、键盘操作、异常提示、容量检查、实际平台验证 | 可日常使用的本机 MVP | P0 验收通过，环境与启动说明可复现 |
| M5 后续增强 | AI 整理、更多模板、其他工具 | 独立增量 | 另行确认每项需求范围，不阻塞 M4 |

单人实施粗估：M0 1–2 天，M1 2–3 天，M2 4–6 天，M3 3–5 天，M4 2–4 天，合计约 12–20 个工作日。估算不包含大规模改版或新增复杂导入；M0 后依据分页难度重新估算。

## 4. 有价值的测试范围

### 单元与属性测试

- 文档格式转换、码点计数、UTF-16 范围/字素簇安全切分。
- 分页后每个可见内容块完整覆盖且无重复；使用随机长度和多标点样例发现边界问题。
- 标题适配边界、显式分页保留、连续分页去空页。
- 草稿版本冲突、旧任务不能覆盖新文档。

### API 与 PostgreSQL 集成

- 合法及非法请求、上传图片实际解码、越权资源访问。
- 幂等重复请求及并发 key 冲突。
- 多 worker 领取同一任务时只允许一个有效租约；过期旧 worker 不能提交。
- 取消与成功竞态、崩溃回收、24 小时结果过期及文件删除重试。
- 用真实 PostgreSQL 16 验证事务锁和 JSONB，不用 SQLite 模拟关键队列语义。

### 浏览器端到端

- 从首页进入 → 粘贴 → 修改品牌 → 生成高清预览 → 下载 ZIP。
- 断网编辑、恢复、导入备份、多标签冲突。
- 手机操作和单图下载、键盘操作、焦点管理。
- 图像输出人工检查：Logo、字体、标题强调线、正文边界、页码、跨页阅读。

不为静态文档或简单样式赋值编写镜像测试；测试集中于数据丢失、分页错误、状态竞态、下载一致性等实质风险。

## 6. 初始性能目标

记录测试机器 CPU、内存、系统、浏览器及冷/热启动状态后再评价，以下为目标，不是当前实测：

- 首页本地服务启动后 2 秒内可交互。
- 约 1,500 字文章，单次编辑防抖后即时草图更新 P95 ≤800ms，连续输入不卡顿。
- 5 页 1080×1440 PNG，字体已缓存、单任务热启动时，高清渲染 P95 ≤15 秒。
- 20 页压力样例可完成且不崩溃；进度持续可见；峰值内存记录并据此调整并发。
- 草稿变化后约 1 秒发起保存；存储成功后才更新状态。
- 超出目标时先定位字体加载、测量次数、图片内存和任务排队，不能靠缩小输出尺寸或删减文本“达标”。

## 7. 首版完成定义

1. 所有 P0 主流程可用，正文不丢失、不重复、不越界。
2. 真正下载 PNG/JPG 和 ZIP，并通过像素尺寸、页数和文件一致性检查。
3. 高清预览和下载对应同一快照；编辑期间的旧结果有清晰提示。
4. 任务失败、取消、进程重启后能恢复或明确失败，不无限等待。
5. 草稿恢复和备份可以重新生成作品，无需原服务端任务。
6. 浏览器间临时资源隔离正确，日志无正文和密钥。
7. Windows 本地 Python + React + PostgreSQL 启动步骤已实际执行，无 Docker。
8. 实际平台展示效果有记录。若尚无上传验证条件，明确标注“平台展示未验证”，不得宣称已验证全景效果；本机功能验收可单独完成。

## 8. 风险与处置

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 中文断行比预期复杂 | 阅读体验差、孤字 | M0 提前验证；明确回退策略和人工控制 |
| 字体文件较大或加载失败 | 首次慢、排版变化 | 自托管、缓存、版本固定、失败可见 |
| 手机浏览器保存行为不同 | 用户无法找到图片 | 单图入口、实际设备验证、操作说明 |
| Windows 浏览器子进程异常 | 无法出图 | 独立 worker 和同步 Playwright 先验证 |
| 公开匿名服务被高频调用 | 资源耗尽 | 限额、队列、超时；公开部署另做评估 |
| 平台裁切/压缩变化 | 上传后字号或布局变化 | 保持预设可配置，真实 App 验证 |
